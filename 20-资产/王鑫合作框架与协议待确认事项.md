# 王鑫合作框架与协议待确认事项

> [!warning] 文件性质
> 本页是对 WorkBuddy 记忆和两份协议草案的业务整理，不是正式合同，也不是法律意见。当前文件仍包含大量待填写项，知识库中没有已签署版本或实际付款记录。

## 一、合作目的

- 王鑫负责引荐企业客户及地方政企渠道资源；
- 我方负责企业 AI 咨询、辅导陪跑、本地化部署对接和项目交付；
- 双方希望共同拓展企业服务业务并持续维护客户关系。

## 二、草案中的主要安排

- 利润分配：我方 60%，王鑫方 40%；
- 收支核算：以合作项目收入扣除约定成本后的净利润为基础；
- 查账权：王鑫方可按约定查阅合作业务的收入、成本、流水和凭证；
- 开票与付款：草案采用对公转账，由王鑫公司开具咨询服务发票；
- 客户范围：草案写入王鑫引荐客户和我方自行开发客户均纳入合作范围；
- 合作期限：草案建议 3 年，期满可续；
- 代持安排：另拟三方代持股协议，草案暂按 40% 股权权益表达。

## 三、必须在签署前统一的冲突

### 1. 资金流向存在两种说法

- WorkBuddy 长期记忆记录的是：款项直接进入王鑫公司账户，由王鑫公司开票；
- 《咨询服务合作协议》草案写的是：业务先通过我方公司账户，我方向王鑫公司支付利润分配款。

必须选定一种真实可执行的收款、开票和结算流程。

### 2. 净利润口径发生变化

- 早期框架强调扣除“约定可扣除成本”；
- 当前草案扩大为扣除与合作相关的“全部运营成本”。

需要列出可扣除成本清单、分摊规则、凭证要求和双方确认机制，否则 60/40 没有稳定的计算基础。

### 3. 利润分成与股权权益需要明确关系

代持草案把 40% 利润分配权与 40% 股权权益写成“同一权利的两种表述”，但股权还涉及表决、增资、亏损、债务、退出和税务。双方需要明确：

- 王鑫是否实际出资；
- 40% 是项目利润分成、公司股权，还是两者之一；
- 是否参与公司全部业务，而不仅是合作项目；
- 是否承担亏损和追加出资义务；
- 退出和回购如何定价。

### 4. 客户范围过宽，需要列明边界

“我方自行开发的客户也全部进入合作范围”会直接影响未来其他渠道和项目。需要确认适用行业、客户清单、保护期、项目类型和例外情形。

## 四、草案尚未填写或确认的事项

- [ ] 双方公司主体、法定代表人、统一社会信用代码和地址；
- [ ] 王鑫公司收款账户与开票信息；
- [ ] 利润结算周期和异议期限；
- [ ] 可扣除成本完整清单；
- [ ] 王鑫工资或固定报酬安排；
- [ ] 查账频率和资料范围；
- [ ] 代持人身份、出资情况和准确股权比例；
- [ ] 客户归属、保护期和禁止绕开条款；
- [ ] 违约金、退出、回购和争议处理；
- [ ] 协议正式签署日期和编号。

## 五、建议的完成顺序

1. 先用一页商业条款清单确认双方真实意思；
2. 统一资金流、净利润、客户归属和股权性质；
3. 让会计核对开票、成本和税务流程；
4. 让执业律师审核合作协议与代持安排；
5. 补齐所有主体信息和附件；
6. 双方签署后，将签署版作为唯一有效版本重新同步。
