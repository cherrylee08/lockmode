# VPN搜索受限观察与竞品核查清单
+
+日期2026-11-20；本轮来源为用户陈述，尚未独立核验手机/网页搜索结果，也未收到竞品链接。不把本笔记当作已完成竞品分析。
+
+## 新观察
+
+- 用户在手机VK和电脑网页搜索VPN，发现多数带VPN名称社群不可见，带VPN名称的个人也很少；具体筛选、排名范围、网络、身份与时间截图未保存到本次记录。
+- 用户曾发正文含VPN的内容，目前未发现该内容因此被封，但流量未明显增长。内容版本/时间和通知原件本次未取到。
+- 用户观察几个竞品发过少数帖子后，粉丝继续涨而停止更新；链接、帖子与逐时点粉丝记录待提供，不能确认自然新增、来源或未使用其他分发。
+
+## 待验证解释
+
+“VPN查询或特定对象存在过滤”是候选，不是已确认全站规则；两个设备可能仍共享身份、网络或地域，不能直接当独立地域复核。“搜索增多就被封”目前只有历史先后关系，未识别处置原因或阈值；“少发/停更能保留排名”也未被证明。不要据此寻找隐藏广告、拆字或轮换IP规避限制。
+
+## 当前操作建议
+
+先区分搜索入口：社群、帖子、个人，精确名称/品牌与VPN通用查询分别记录。不因一次前30未见断定被移出搜索。页面直达可打开、精确查询可见、通用查询排名和明确限制通知是不同证据。
+
+不立即把全部社群转向正文SEO：11/13继续现行观察，正文候选只测真实相关知识内容，不能承诺它提高社群排名或更不易封。真正要确认的是哪个入口、哪个查询、何种条件持续带来外部入站，而非只看粉丝总数。
+
+## 收到竞品链接后的只读比较
+
+优先3—5个用户最关注的链接，附实际发现它的查询词（记得才补，不阻止先看链接）。逐个记录：
+
+1. 对象是社群还是个人，固定ID/地址、当前可达/明确限制；不收集私聊或会员身份。
+2. 当前准确名称、简介、可见历史创建/改名日期；名称是否曾变，不能用现名倒推早期名字。
+3. 原创/转发、发布数量与日期、最后更新、置顶、视频/文章/正文关键词、真实产品身份/入口，标题和正文分别保存。
+4. 同身份/网络/过滤下，VPN、ВПН、DPN及实际发现词是否找到它；固定前30范围、入口和排序/日期；不使用虚构排名。
+5. 公开浏览、赞评转与粉丝数仅作规模/互动；在多个时点确认增长，不凭总量认定新增客户。公开页不能确定自然/投放/外部渠道时标未知。
+6. 区分“仍占搜索位”与“旧内容继续被浏览”“外部有人导流”“仅粉丝增加”；先检查前者是否真实，再讨论少发原因。少发是观察特征，不是原因。
+
+输出表：名称/简介/年龄与历史/内容词与形式/更新节奏/实际查询位置/公开增长证据/可复制候选/无法证实项。先提出跨样本共同特征，后选一个真实且适用因素复验；不同时复制所有字段，不把竞品存活当保证。
