# Deeper 短片生产与验收清单

## 生产前

- [ ] 明确本集唯一产品价值，不同时讲多个功能。
- [ ] 指定 Dex、Mary、Pip 的唯一参考图；旧版和变形版从参考集移除。
- [ ] Logo 矢量几何锁定：模型只可改变材质与正常透视，不可重画双旋结构。
- [ ] 明确正式角色名称；Mary/Mira 混用必须在发布前清除。
- [ ] 准备真实 App 的未连接、点击、连接成功画面；不要求生成模型绘制准确 UI。
- [ ] 确认 CTA 版、无 CTA 版、长版、短版的命名规则。

## 提示词规则

- [ ] 把“人物身份、外观、服装、坐标、道具”写成绝对连续性规则。
- [ ] 写清人物表演弧线，不只写对白。
- [ ] 环境必须持续有微运动；避免“静态图片在说话”。
- [ ] 转场遵循 **WORLD CHANGES. FAMILY DOESN’T.**：摄影机、人物和关键道具坐标不变，只有空间重构。
- [ ] D–PER 是克制、快速、干净的数字扫描/空间重算，不是魔法门、虫洞、蓝色漩涡或粒子爆炸。
- [ ] 不让视频模型承担小字、国家名、按钮和 App 界面的精确重现。

## 单镜头验收

- [ ] 角色脸、耳朵、眼睛、肤色、服装与定妆图一致。
- [ ] 手指、手机尺寸和点击动作自然；屏幕角度便于后期替换。
- [ ] 前后镜头的人物位置、视线、身体重心和道具位置可接。
- [ ] 背景有人类生活痕迹和自然运动，但不抢人物表演。
- [ ] 地域辨识来自真实生活环境，不堆砌旅游符号。
- [ ] 没有模型擅自增加人物、Logo、文字、旗帜或不存在的产品功能。

## 后期与交付验收

- [ ] 用真实 App 画面替换手机屏幕；检查运动跟踪、透视、反光、手指遮挡和亮度。
- [ ] D–PER 声音与触发帧、空间扫描、Logo 出现节奏一致。
- [ ] CTA 只出现在指定版本；无 CTA 版片尾干净。
- [ ] 字幕、产品名和国家名无拼写错误。
- [ ] 音量、对白、环境声和品牌声在手机扬声器上仍清晰。
- [ ] 导出后从头到尾检查黑帧、跳帧、重复帧、画面拉伸和色彩突变。
- [ ] 成片写入版本号、日期、时长和用途；不要只用“最终版”“真的最终版”区分。

## 建议命名

`DN_EP01_Hank_v1.0_30s_CTA_2026-09-17.mp4`

字段依次为：品牌、集数、短标题、版本、时长、用途、日期。
